# Bounty Vibe

## Description

Bounty Vibe est une plateforme de référence pour les joueurs de Star Wars: Galaxy of Heroes (SWGOH). Ce site centralise des guides détaillés sur les meilleures équipes du jeu, avec des recommandations précises sur les compositions, les mods et les statistiques optimales. Les informations sont soigneusement sélectionnées et mises à jour pour offrir aux joueurs une source fiable d'optimisation de leur roster.

## Fonctionnalités principales

- **Guides d'équipes** : Analyses détaillées des meilleures compositions d'équipes
- **Recommandations de mods** : Configurations optimales pour chaque personnage
- **Statistiques cibles** : Valeurs de statistiques à atteindre pour une performance optimale
- **Mises à jour régulières** : Contenu maintenu à jour avec les dernières méta du jeu

## Technologies utilisées

- Next.js
- React
- TypeScript
- Tailwind CSS (pour le design moderne et responsive)

## Objectifs du projet

- Devenir une référence incontournable pour les joueurs SWGOH
- Fournir des guides précis et détaillés sur les équipes
- Aider les joueurs à optimiser leur roster de manière efficace
- Maintenir une base de connaissances à jour sur les meilleures stratégies
